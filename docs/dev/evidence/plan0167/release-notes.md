# Codex Wake v0.17.0

When a user supplies `/goal` token/time limits, agents can enroll their existing
native session through MCP. An independent watcher requests a checkpoint, then
pauses the current goal and interrupts its exact active turn. Counters and the
original deadline survive goal replacement, resume and controller restart;
only an explicit host-approved user reset can reset allocation.

- Cached-inclusive sampled accounting attributes root and delegated responses
  once. Unknown history/accounting holds continuation. Token overshoot is unknown.
- Dedicated approved executors separately provide systemd/cgroup resource limits.
  Their first strict bootstrap remains operator-provisioned.
- Packaged agent instructions and tool discovery explain setup, status, reset
  authority and limits. Wheel installation alone does not synchronize skills.

Native-session stop proof covers the registered session, not separately running
children or arbitrary tool processes. Host grants, a qualified clock and a live
independent watcher are required. No existing session is enrolled by installation.

Validation includes isolated regression, public MCP/controller qualification and
actual native idle/active controls and delegated accounting with localhost
Responses fixtures. Fixture usage is not billing, and checkpoint delivery is not
proof of an authored checkpoint. Canonical receipts are in Plan0167 evidence.
