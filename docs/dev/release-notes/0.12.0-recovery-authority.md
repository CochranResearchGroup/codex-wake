# Codex Wake0.12.0 recovery authority

Recovered buses can explicitly retain unknown snapshot-era work, then release the
hold into paused operation under fresh authority. `a2a recovery-status`,
`dispose-recovery` and `release-recovery` pin the recovery epoch/snapshot commitment
and record attributable, repeat-safe receipts. Release does not resume, enroll,
rotate actors, process old work or infer unavailable outcomes.

Disposed recovered buses use bus schema3. Old0.11.2 readers explicitly refuse
these stores; normal schema1/2 buses stay supported. Rollback does not downgrade a
schema3 bus or replay its records. Keep the qualified new reader available for
inspection and retain quarantines, snapshots and receipt history. Production
recovery/hold release requires explicit store-specific authorization.

Installed validation, review, integration and final campaign release remain gates.
