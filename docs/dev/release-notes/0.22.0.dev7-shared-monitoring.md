# 0.22.0.dev7 | Shared wake monitoring

Ordinary enrolled roots can share bounded process workers with independent
polling intervals. Canonical-root ownership prevents overlapping polls by upgraded
monitors. Hung or abandoned polls retain explicit reconciliation holds. Read-only
service inventory reports overlap and resource samples. Existing roots inherit
supervisor cadence unless poll_interval is explicitly configured; wake records
and dispatch authority are unchanged. Retains dev6 stable tab management.

Upgrade all prospective owners before relying on exclusion. Existing processes
keep their loaded build. Preserve native children when replacing monitor owners;
qualify rollback and root-specific acceptance before migrating working roots.
See docs/dev/service-consolidation.md. Zsh completion refreshes on installation.
