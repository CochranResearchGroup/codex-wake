# Codex Wake 0.14.0 — Governed agent lifecycle

Adds public CLI/MCP spawn, same-thread resource refresh, fresh-agent handoff and
rollback, with exact native identity and durable effect reconciliation. Host
configuration selects full writer/reviewer instructions and per-session plus
cumulative objective token/time limits. Runtime readiness and evidence-based
work review are separate gates. Corrective work stays inside a frozen packet
and stops after two cycles; original deadlines and spending survive transitions.
Operator budget authorization retains history; agents cannot reset allowances.

Existing wake records, basic session operations and tracked A2A remain compatible.
Lifecycle launch profiles require explicit host approval and owned runtime proof;
legacy preflight-only profiles cannot activate a successor under the new contract.
No global daemon restart, claim transfer, implicit enrollment or quota renewal.
A resident owned controller is required for autonomous lifecycle supervision.

Native candidate proof covers both tab modes, selected Matt instruction reads,
review/continuation/rollback, actual cached-token accounting, accepted repair and
exact two-cycle rejection. Configured refresh proves original goal continuity,
updated resource behavior and stale-MCP rejection. Replacement/restart budget
bounds and non-GitHub selections also have installed public-fixture coverage.
Failed samples remain recorded. Released-prefix CLI/MCP/skill qualification and
exact-main installation are separate closeout gates.
