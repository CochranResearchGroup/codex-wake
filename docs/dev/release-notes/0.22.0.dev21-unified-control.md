# 0.22.0.dev21 | Unified connector control

Seven canonical resource families gather Byobu environment, wake, program,
account/harness, operation and connector controls across CLI/API/MCP. Legacy entry
points retain their owners; native caller and protected OAuth admission stay distinct.

Adds exact existing-turn snapshot observation, rendered terminal observations and
explicit paste/keys, explicit native busy-input policies and live park/restore,
scoped connector grants/registered owning-host management, bounded select/while,
typed semantic results, and durable frozen bulk runs using the existing executor.
Generated metadata and portable client names describe the canonical contract.

Existing wake records and flows are retained. New program nodes need this reader;
older processes do not gain the new capabilities until explicitly replaced.
Registration is not runtime readiness. Native push, unqualified pickers/headless
detach, exact semantic metering and live/Windows acceptance remain unsupported or
unqualified as documented. No production schedules, grants or native runtimes are
changed by building/installing a disposable validation prefix.
