# Wake0.9.0 native workflows

Installed0.9.0 rollout is qualified. Release publication remains pending.

Native Codex owns conversations, ordinary messages and turn execution. Wake
adds exact-thread durable time/file follow-ups, expiry, same-thread resume,
uncertain submission reconciliation and visible tab lifecycle. Official
Codex0.162.1 is qualified by actual disposable client/scheduler acceptance.
No custom Codex patch is required.

Basic classic time/file callers must now explicitly choose `--legacy-tmux` or
an app-server target. Use `native after|at|file THREAD_UUID TRIGGER` for the
qualified native path. Existing persisted legacy records still dispatch;
advanced signals and tracked-mailbox receipt contracts remain supported.

Native records use schema4 so older readers hold them safely. Earlier candidate
native schema1 records have an explicit preview/apply migration that preserves
original state and never submits work. [Migration and rollback](../native-workflow-migration.md)
explain same-root restore, unknown-version hold and compatibility boundaries.

Queue acceptance is not execution or acknowledgment. Uncertain work never
blindly resends or falls back. Closing a tab preserves its conversation; force
preserves affected work and cancellation/archival remain separate operations.

Native network-time parity, arbitrary future Codex versions, cross-host work
and advanced signal replacement are not claimed.

## Installed acceptance

Normal user entrypoints report0.9.0. The existing supervisor was upgraded after
all four registered roots had zero pending/firing work. Root registrations and
old package bytes were preserved; unrelated unit PIDs remain unchanged.
The native sender assigned a visible worker, armed a file follow-up, ended its
turn and resumed15 seconds later through the normal supervisor, read exact42
and displayed its response. Busy/pending close guards, separate cancellation
and conversation-preserving close passed. Failed worker formatting and selector
probe samples remain recorded. Owned fixture clients exited; histories and
uncertain/signal/mailbox controls remain retained.

The local versioned installation preserves older workers' module files. See
[deployment/migration](../native-workflow-migration.md) before upgrading other
root readers or replacing retained package-manager environments.
