# 0.22.0.dev9: automatic tab-monitor startup

Local `tabs startup enable|disable|status` manages an owned per-controller systemd
user unit. Startup keeps saved monitor settings and discovers terminals that
appear later. It follows normal user-manager login/boot behavior without changing
linger or launching terminals or agents.

Opt-in `recover_namespace` permits enabled, unpaused workspace formatting to
capture replacement namespace originals while retaining prior originals. It is
false by default; rollback, pause and unavailable-source holds remain effective.
Existing schema-version1 state remains compatible. Disable startup before package
rollback to a version without the startup commands; the older foreground monitor
remains available through the retained package.
