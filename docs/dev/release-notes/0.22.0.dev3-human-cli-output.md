# 0.22.0.dev3 | Human-friendly CLI output

Human-facing controller and agent command adapters now honor their output
selection. Ordinary invocations show readable tables and labeled details;
`accounts list` shows ACCOUNT, ALIASES and HOME instead of an internal envelope.
Nested history content and meaningful ownership remain visible. Account login
and native authentication status retain native stdio.

Compatibility: automation that parsed unflagged JSON must add `--json` to the
leaf command. Explicit JSON keeps complete operation envelopes and exact target
pins. Build workflows retain `--output json`. Exit statuses are unchanged.
SSH receiver frames, explicit streams/transcripts, controller remote/API/MCP
and stdin permission frames retain their structured protocols.

See [CLI output](../../agents/cli-output.md). This package changes CLI presentation; native daemon binaries and runtime owners
are unchanged. Package deployment uses exact merged source with rollback retained.
