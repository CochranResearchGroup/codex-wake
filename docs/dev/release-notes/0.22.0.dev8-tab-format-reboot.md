# 0.22.0.dev8: formatting recovery after terminal server replacement

`codex-wake tabs format enable` can establish formatting on a replacement terminal
server without losing the previous server's original settings. Earlier namespace
baselines remain retained, and returning namespaces reuse their originals.

Status and inspect now explain stale baseline custody without modifying it.
Rollback, automatic refresh and requests pinned to the old server retain their
identity checks. Recovery remains an explicit enable action after reboot.

The additive `retired_workspaces` map keeps schema-version1 compatibility.
Older packages ignore that retained map; keep it intact during package rollback.
