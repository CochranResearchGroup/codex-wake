# 0.22.0.dev10: remove the tmux subscription crash trigger

The retained metadata feed no longer installs native `refresh-client -B`
wildcard pane/window subscriptions. Ubuntu tmux3.4 can dereference a missing
session from its subscription timer while a closing control client is stalled,
crashing the entire server and all sessions. The incident and actual-feed
regression reproduce this without writing any tab-format options.

The feed retains its read-only control connection and normal change events.
One fixed metadata snapshot per second observes pane/title changes without native
subscription timers or per-tab processes. Ownership, output/time bounds and
redacted observations remain enforced.

Incident containment keeps production formatting globally disabled and startup
stopped/disabled. Installing this package does not re-enable them or restart
Byobu. Review the retained incident/qualification receipt before any reactivation.
