# 0.22.0.dev8 — Task governor and native controls

Integration candidate for #570: ordinary task activation, retained usage windows, direct operator lifecycle controls and typed CLI/API/MCP interfaces. The accompanying retained Codex0.167 patch adds /wake, guided controls and persistent governor presentation without inference. Stock Codex stays independent.

Task windows begin at successful qualified activation. Existing enrollment semantics and lifetime evidence remain readable. No automatic renewal through reconnect or delegation. New native UI requires the corresponding separately qualified modded package; installing Python alone does not add /wake to an old native executable.

Implementation and installed native qualification are in progress in Plan0220. Do not treat this release note as deployment acceptance.
