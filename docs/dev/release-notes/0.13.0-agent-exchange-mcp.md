# Codex Wake0.13.0 — Agent exchanges through MCP

Adds the optional codex-wake-mcp stdio server with14 discovery/mailbox tools,
backed by the existing CLI. Install the mcp extra. The main README and agent
skill now advertise tracked requests, work claims, correlated replies and
suspended follow-up; docs/agent-to-agent.md and docs/a2a-mcp.md explain setup.

Actor capability, bus and runtime endpoint remain host-selected. Each message
call supplies the actual caller_thread_id, obtained from native shell context;
the unchanged CLI validates it against runtime, root and fixed capability.
This explicit claim is not caller attestation. Unknown credentials/operator
arguments are rejected. No new bus, dispatcher or worker is created by MCP.

No mailbox/wake schema or domain behavior changes. CLI-only installation remains
supported without MCP dependencies. Timeout/invalid-response uncertainty retains
original intent and never silently retries. Metadata tools conservatively declare
legacy expiry/clock mutation; bodies retain their untrusted-content marker.

Validation: focused MCP/mailbox/claim tests; actual installed stdio discovery and
private inbox request/reply/dedup/claim/completion, wrong-capability and shared
connection child-claim refusal, with zero native turns/notifications and owned
root/process cleanup. Existing native A2A transport acceptance remains independently
