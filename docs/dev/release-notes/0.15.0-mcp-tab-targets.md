# Codex Wake 0.15.0 — MCP tab targeting

Agents can pass Byobu names, indexes and bounded spelling variants directly to
MCP. `wake_sessions_target` inspects or prepares targets; message send resolves,
pins and revalidates exact thread/pane identity inside Wake. Missing, dormant,
busy, ambiguous, changed and unavailable targets have distinct structured results.

Independent missing/inactive policies select error(default), tab-only, fresh or
resume using host-approved launch profiles and fixed intent/expiry. Dormant shells
are preserved. Saved sessions are scoped to exact canonical CWD; explicit saved
IDs require matching native metadata. Uncertain startup reconciles known identities
without replacement effects; unknown effects remain held. No automatic enrollment,
claim transfer, budget reset, shell key injection or shared-service restart.

Existing UUID sends and wake schemas remain compatible. Detailed shell metadata
is opt-in for target preparation; existing lifecycle inventory keeps its shape.
Agents should send informal descriptors directly through MCP rather than enumerate
tabs or repair spelling in the CLI. New MCP clients advertise19 tools; existing
clients need an ordinary resource/session refresh to load the new tool schemas.

Source and isolated installed evidence is in Plan0162. Deployment qualifies an
exact merged-main artifact, executable/skill parity and owned startup cleanup;
it does not establish production-peer message execution or refresh existing TUIs.
