# Codex Wake 0.16.0 — Wake emergency controls

Adds explicit registered-root inventory, bulk cancellation, persistent per-root
pause/resume/status, and separate Wake-owned native interruption. Six new MCP
tools use host-owned per-caller root/action grants and frozen scope binding.

Pause holds future dispatch and lifecycle admission/activation without cancelling
records or interrupting existing turns. Interruption requires an already paused
root and exact owned assignment evidence; handoffs depend on their resident owner.
Uncertain effects stay held for reconciliation. Sidecars retain private fsynced
state/history; wake record schemas are unchanged. See docs/wake-emergency-controls.md.

Every responsible reader must run control-capable code. Older resident workers
ignore the new protocol; install/readback cannot certify their upgrade. Runtime
receipts distinguish an observed capable reader from an exclusive process census.
Newly registered roots after an all-roots snapshot are outside its scope.
No OS process kill, OpenClaw service work, queue-retraction claim or budget reset.
