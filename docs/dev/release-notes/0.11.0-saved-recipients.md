# Wake0.11.0 explicit saved recipients

Messages wait when their recipient's Byobu tab is closed. Senders can explicitly
request --resume-missing on send/reply to reopen only that same saved conversation.
The choice survives restart and is part of the immutable idempotent intent.
Original actor IDs, capability generations and roots are rechecked; reopening
does not grant mailbox access. Live tabs retain busy and composer protection.
Replies retain delegated sender-arm authority and require their own opt-in.

The normal worker delivers a body-free original mailbox pointer under its existing
journal-fenced attempt. Unqualified lifecycle/queue effects stay uncertain and are
never replayed automatically. Missing runtime or changed identities hold visibly.
No new database schema, default reopening, Codex patch or daemon restart is needed.
Older workers retain their existing offline hold behavior; rollback does not
replay submitted or uncertain effects. Do not rotate credentials to release a
held original request: changed permission generations require an explicit new intent.

Source regression and installed acceptance receipts are maintained under
docs/dev/evidence/plan0138/. Release and installed qualification remain pending
until that plan's closeout. HostedCI waiting is operator-waived.
