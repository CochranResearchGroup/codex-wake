# User Hook CLI

Date: 2026-05-22

Request: make user-scope hook management first-class instead of requiring
manual `~/.codex/hooks.json` editing.

## Change

Added:

```text
codex-wake hook user install
codex-wake hook user check
```

These commands manage `$CODEX_HOME/hooks.json` when `CODEX_HOME` is set,
otherwise `~/.codex/hooks.json`. Existing project-local commands remain:

```text
codex-wake hook install
codex-wake hook check
```

The user commands do not bypass Codex hook trust. They only write or inspect
the user-scope hook config.
