# Status JSON Summary Surface

Date: 2026-05-20

Lane: P24

## Scope

Add compact `codex-wake status` and `codex-wake status --json` runtime summaries for supervisor automation.

## Changes

- Added `status_summary()` in the record layer.
- Added `codex-wake status`.
- Added `codex-wake status --json`.
- Summaries include wake root, total count, active total, terminal total, archived total, counts by status, counts by predicate type, counts by target transport, and earliest pending or firing `next_attempt_at`.
- Updated README usage.
