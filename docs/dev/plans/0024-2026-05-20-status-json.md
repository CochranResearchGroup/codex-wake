# Status JSON Summary Surface

Date: 2026-05-20

## Scope

Add a compact `codex-wake status` and `codex-wake status --json` surface that summarizes wake counts by state for supervisors and automation.

## Non-Goals

- Do not change wake record schema version.
- Do not replace `list --json` for full record inspection.
- Do not add service health or hook readiness; `doctor --json` owns that surface.
- Do not persist a derived index.

## Current State

Closed by [Status JSON Summary Surface](../verification/0026-2026-05-20-status-json.md).

## Plan

- Add a pure record-layer summary function that reads current JSON records and archived records.
- Count records by status.
- Count records by predicate type and target transport.
- Include `earliest_next_attempt_at` for pending and firing records.
- Add `codex-wake status` text output and `codex-wake status --json`.
- Document the command in README.

## Acceptance Criteria

- `codex-wake status` emits stable text key-value diagnostics.
- `codex-wake status --json` emits valid JSON.
- JSON includes wake root, totals, counts by status, active total, terminal total, archived total, predicate counts, target counts, and earliest next attempt.
- Tests cover the summary logic and CLI output.
- Installed CLI smoke verifies `status --json`.

## Definition Of Done

This lane can close when source tests and installed CLI smoke verify the status command, and verification evidence is recorded.
