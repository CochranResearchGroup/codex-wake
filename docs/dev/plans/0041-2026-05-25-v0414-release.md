# v0.4.14 Release

Date: 2026-05-25

## Scope

Release the OpenClaw Gateway wake transport from P40, the repo-linked OpenClaw
`codex-wake` plugin, and the transport-selection skill hardening from
`183767d Clarify codex-wake transport selection`.

## Non-Goals

- Do not change wake record schema version.
- Do not change tmux dispatch semantics.
- Do not change Codex app-server dispatch semantics.
- Do not solve a standalone OpenClaw plugin packaging format beyond the
  repo-linked plugin shipped in this tag.
- Do not run a new live OpenClaw wake if existing P40 live smoke evidence and
  release validation cover the release boundary.

## Current State

`main` contains the closed P40 OpenClaw Gateway transport/plugin work and the
skill transport decision hardening. The package version is still `0.4.13`;
downstream installs need a tagged release to pin the new `openclaw_gateway`
CLI/runtime support.

## Acceptance Criteria

- `pyproject.toml` version is set to `0.4.14`.
- Release notes exist under `docs/releases/v0.4.14.md`.
- README GitHub install example points at `v0.4.14`.
- Source tests, compile checks, plugin tests, node syntax checks, and diff
  checks pass.
- A wheel and source distribution build successfully.
- A temporary installed-wheel smoke verifies the Python package version and
  OpenClaw CLI surfaces.
- Installed skill copies remain synced and OpenClaw can see the `codex-wake`
  skill.
- The release commit and `v0.4.14` tag are pushed.
- GitHub release exists for `v0.4.14`.
- Public tag install smoke confirms version `0.4.14`.

## Definition Of Done

This lane is complete when validation evidence is recorded under
`docs/dev/verification/`, CI passes on the release commit, the tag and GitHub
release are public, public tag install verifies the package, the user-scoped
tool install is refreshed, and the repo returns to a clean state.
