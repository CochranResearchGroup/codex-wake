## Scope and frozen contract

Implement immutable envelopes, independent admission/notification/recipient
projections, transactional idempotency and recipient FIFO sequence, append-only
attributable receipts, and a transactional notification/receipt outbox. Public
verbs: send, inbox/outbox, show/read, ack, reply, cancel, bounded wait/watch and
read-only reconciliation. No automatic delivery or production enrollment here;
notification intents remain journal-authorized pending scheduler qualification.

Core bus policy schema remains version 1. Explicit operator migration adds a
separately versioned mailbox domain in the same journal; mailbox readers reject
unknown domain versions. Existing actor/enrollment data survives migration.
Actor authority and enrollment are revalidated within every mailbox transaction.
An exact recipient is pinned before admission. Stable fingerprint uses requested
TTL rather than a newly sampled absolute expiry, so retries after interruption
return the original committed envelope and original expiry; differing TTL is a
conflict. An explicit machine idempotency key is required. No hidden resend.

First body read records received, not a work claim. Accepted disposition creates
one stable processing claim. Repeating a claim returns its original receipt;
rotation/restart does not erase deduplication. Terminal transitions are explicit
and cannot be contradicted. A previously accepted claim may report a late outcome.
Cancelled/expired messages remain inspectable; no new first claim is permitted.
Reply keeps conversation and ancestry, targets only the original sender, and
optionally commits an outcome with the reply in one transaction. Reply never
silently marks completed. Cancellation after dispatch claim is too late/uncertain.

## Acceptance

Deterministic tests cover concurrent identical sends, conflicting keys, crash
before/after commit, reopened journals, independent recipient receipts, duplicate
processing acceptance, reply/optional-ack atomicity, first-claim expiry, late
outcomes, cancellation races, FIFO, capacity/rate/hop bounds, clock regression,
unknown schema, private body filtering, and exact mailbox authorization. Installed
provider-free CLI workflow must exercise send/read/ack/reply across two explicitly
issued disposable identities. Wider delivery/live gates remain in Plan 0101.
