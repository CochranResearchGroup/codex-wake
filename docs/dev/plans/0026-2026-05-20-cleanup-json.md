# Cleanup JSON Surface

Date: 2026-05-20

## Scope

Add `codex-wake cleanup --json` so operators and supervisors can preview terminal archiving and archived-record deletion candidates without parsing text output.

## Non-Goals

- Do not change cleanup safety defaults.
- Do not delete active `pending` or `firing` records.
- Do not add background automatic cleanup.
- Do not change wake record schema version.

## Current State

Closed by [Cleanup JSON Surface](../verification/0029-2026-05-20-cleanup-json.md).

## Plan

- Add `cleanup --json`.
- Keep text output stable.
- In JSON mode, emit:
  - cleanup mode and retention window
  - archived terminal records moved during `--archive-terminal`
  - matched archived records that would be deleted or were deleted
  - counts for archived terminal records and matched cleanup records
- Keep runtime state mutations identical to the existing command.

## Acceptance Criteria

- `cleanup --json` emits valid JSON in dry-run mode.
- `cleanup --json --archive-terminal` reports archived terminal records.
- `cleanup --json --delete` reports deleted archived records.
- Existing text cleanup output remains covered.
- Installed CLI smoke verifies JSON cleanup output.

## Definition Of Done

This lane can close when source tests and installed CLI smoke verify the JSON cleanup output, and verification evidence is recorded.
