# Issue tracker: GitHub

Canonical target: github.com / CochranResearchGroup/codex-wake.
GitHub Issues owns intake, priority and discussion. Repository plans, ROADMAP,
RUNBOOK, validation and release receipts retain their distinct authority.

Read docs/dev/forge-issue-targets.json and the applicable forge/GitHub policy
before mutations. Use gh with explicit --repo CochranResearchGroup/codex-wake;
never infer a write target from a working directory or similarly named fork.
Use --body-file for multiline bodies and comments. Read back each mutation;
reconcile ambiguous results before any retry. Authentication is not authorization.
Every triage-posted comment or issue starts with:
> *This was generated by AI during triage.*

PRs as a request surface: no.
An explicitly named PR may still be reviewed. Skills do not authorize live
runtime effects, arbitrary issue mutations or implementation merely by triaging.
