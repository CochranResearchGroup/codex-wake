# v0.5.2

Date: 2026-09-04

## Summary

`v0.5.2` removes a misleading readiness warning when the user supervisor is
already the healthy owner of a repository's wake root.

## Changes

- Added the neutral `not_needed` product-readiness status.
- An inactive repo-scoped service now reports `not_needed` when the user
  supervisor is active, the selected root is enrolled, and monitor evidence is
  ready.
- The structured repo-service result includes `required=false` and
  `covered_by=supervisor` in that configuration.
- An inactive repo service remains a warning when healthy alternative coverage
  cannot be proven.
- Neutral results do not raise the overall readiness severity.
- Made the focused product-readiness test module independent of test import
  order.

## Compatibility

Wake-record schema version remains `1`. The readiness status vocabulary gains
the additive `not_needed` value; existing warning and blocked behavior remains
unchanged when supervisor coverage is absent or unhealthy.

`docs/dev/verification/0071-2026-09-04-v052-readiness-release.md`.
