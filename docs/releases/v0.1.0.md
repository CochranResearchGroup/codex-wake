# v0.1.0

Date: 2026-05-18

## Summary

Initial MVP release for the Codex Wake spooler.

This release provides a deterministic wake path for TUI-bound Codex agents:

```text
codex-wake -> .codex/wake trigger JSON -> codex-waked -> tmux paste -> UserPromptSubmit hook ack
```

## Included

- `codex-wake` CLI for `after`, `at`, and `file` wake creation.
- `codex-waked` daemon for polling pending wakes and dispatching ready records.
- `codex-wake-hook` command for installed `UserPromptSubmit` hook integration.
- tmux injection that sends only the canonical wake prompt:

```text
WAKE_TRIGGER_ID=<wake-id>
Resume the scheduled wake task.
```

- Hook context loading from the full trigger JSON.
- Ack files under `.codex/wake/acks/`.
- Per-pane lock files for tmux dispatch.
- Terminal record archival with `codex-wake archive`.
- Experimental stdio app-server target support.

## Known Limits

- A new repo-local Codex hook may require manual `/hooks` trust review before it can run.
- The daemon is a foreground polling process; no service installer is included.
- The verified trigger predicates are `not_before` and `file_exists`.
- The tmux injector uses pane-content heuristics for unsafe-state detection.
- WebSocket app-server dispatch is intentionally deferred.
