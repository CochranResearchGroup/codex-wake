# v0.4.1

Date: 2026-05-19

## Summary

Releases the app-server wake hardening from P18.

## Included

- Added explicit `codex-wake app after <thread-id> <duration> -- <prompt>`.
- Added explicit `codex-wake app at <thread-id> <timestamp> -- <prompt>`.
- App-server dispatch records a `dispatch_attempt` event before app-server requests.
- App-server dispatch persists accepted `thread_id` and `turn_id` metadata in `dispatch_result` when returned by Codex app-server.
- Non-stdio app-server endpoints remain rejected until a documented authenticated transport is implemented.
- P18 validation evidence for source tests and CLI app wake creation smokes.

## Verified

- Source tests and compileall.
- Local package build from a temporary build venv.
- Installed-wheel smoke for `codex-wake`, `codex-waked`, and `codex-wake-hook`.
- Non-wake hook smoke.
- Installed-wheel app wake creation smokes for `app after` and `app at`.
- Clean public tag install and command smoke.
- GitHub Actions CI on the public upstream.

## Known Limits

- The app-server transport currently supports local `stdio://` only.
- CI intentionally does not exercise a live Codex app-server turn submission.
- PID reuse protection for `process_done` predicates remains deferred.
