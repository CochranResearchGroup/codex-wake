# v0.3.1

Date: 2026-05-19

## Summary

Patch release for current-TUI dogfood hardening and CI release gates.

## Included

- Removes stale dead-PID or malformed pane lock files before tmux dispatch.
- Clarifies `codex-wake doctor` and `codex-wake hook check` guidance when `/hooks` does not list a repo hook source.
- Adds GitHub Actions release gates for Python 3.11 and 3.12.
- Records successful current-TUI dogfood evidence with tmux injection, `UserPromptSubmit` context loading, ack persistence, and daemon-submitted status.

## Verified

- Source tests and compileall.
- Local package build from a temporary build venv.
- Installed-wheel smoke for `codex-wake`, `codex-waked`, and `codex-wake-hook`.
- Non-wake hook smoke.
- Tmux-env-only wake creation smoke without live dispatch.
- GitHub Actions CI on the public upstream.

## Known Limits

- CI intentionally does not exercise live tmux paste, Codex hook trust UI, or user systemd service behavior.
- Codex hook entries may appear under the `UserPromptSubmit` or `UserPromptHooks` grouping rather than by command name.
- Current live dispatch remains tmux-specific; app-server targeting is still experimental.
