Qualified native successors can omit the existing objective allocation ID when requesting optional supervision. The adapter resolves the retained source allocation and inherits its accounting basis when omitted. A prior native goal for unrelated work does not lock a new objective. No governor startup or file-read interception is added. Arbitrary Markdown is not verified native lineage or metering proof.
