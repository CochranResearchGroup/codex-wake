# v0.1.1

Date: 2026-05-18

## Summary

Patch release for the user-scoped daemon service path.

## Included

- User systemd service documentation in `docs/daemon-service.md`.
- Example service unit in `docs/examples/systemd/codex-wake.service`.
- Continuous `codex-waked` mode now logs non-empty poll results, which gives user services an inspectable activity trail.
- Unit coverage for daemon poll-result formatting and activity detection.

## Verified

- Source tests and compileall.
- User systemd service install, start, status, log, stop, and disable.
- Dogfood wake through the running user service into a disposable tmux-hosted Codex pane.

## Known Limits

- The example unit is repo-specific and should be copied or edited per repo.
- The service does not trust Codex hooks automatically.
- The service still depends on a safe live tmux Codex prompt when a tmux-targeted wake fires.
