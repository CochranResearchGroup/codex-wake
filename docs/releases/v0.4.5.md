# v0.4.5

Date: 2026-05-19

## Summary

Releases wake record schema versioning and schema inspection.

## Included

- Wake records now have a documented schema version `1`.
- Schema compatibility is documented as additive optional fields.
- Added `codex-wake schema` for human-readable schema metadata.
- Added `codex-wake schema --json` for machine-readable schema metadata.
- Documented required wake record fields, status vocabulary, target variants, predicate variants, optional fields, derived ack files, and schema bump triggers.
- Runtime-state documentation now points to the schema contract and command.
- P22 validation evidence for source tests, source CLI smoke, and installed-wheel CLI smoke.

## Verified

- Source tests and compileall.
- Local package build from a temporary build venv.
- Installed-wheel smoke for `codex-wake schema` and `codex-wake schema --json`.
- Clean public tag install and schema command smoke.
- GitHub Actions CI on the public upstream.

## Known Limits

- Schema version `1` permits additive optional fields without a version bump.
- Required-field changes, status vocabulary changes, predicate semantic changes, and incompatible type changes require a schema version bump.
- The schema command documents the wake-record contract; it does not migrate existing records.
