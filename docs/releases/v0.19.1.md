# v0.19.1

Stable-time consumers reuse a private user-owned Windows counter bridge instead
of launching PowerShell for every clock read. Each read obtains a fresh correlated
native counter; authenticated UTC, age, rate, frequency and uncertainty checks
remain unchanged. The bridge starts automatically, listens only on a private
Unix socket and retires its owned producer after60seconds idle. A cold startup
failure still withholds authority. No mailbox migration or clock reset required.

Fixes the repeated-launch failure qualified under issue302/Plan0171. Source and
installed qualification are recorded separately in that plan.
