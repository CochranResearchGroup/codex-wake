# 0.22.0.dev15

Wake can register persistent specialist bot families and exact per-client terminal
attachments. Family tabs use background workers-session or adjacent placement,
primary-tab reuse, parent/root navigation, readable scope labels and muted accents.
Existing display opt-outs/manual holds and alert styling remain authoritative.
Only successful parent-accepted explicitly temporary idle owned tabs are cleaned;
bot identity/history and manually adopted work remain. Ambiguous effects hold.

The family registry is an independent private version1 record; existing wake and
terminal records are unchanged. This source release does not itself update a
running monitor or provision account/provider access. See docs/bot-families.md.
