# v0.4.0

Date: 2026-05-19

## Summary

Adds event predicates for file changes and process exits.

## Included

- `codex-wake changed <path> -- <prompt>`
  - Wakes when a missing path is created.
  - Wakes when an existing path changes mtime or size from registration time.
- `codex-wake pid <pid> -- <prompt>`
  - Wakes when the registered process ID no longer exists.
- Daemon support for `file_changed` and `process_done` predicates.
- README examples for file-change and process-exit workflows.
- P17 validation evidence for source tests and no-dispatch CLI smokes.

## Verified

- Source tests and compileall.
- Local package build from a temporary build venv.
- Installed-wheel smoke for `codex-wake`, `codex-waked`, and `codex-wake-hook`.
- Non-wake hook smoke.
- Tmux-env-only wake creation smoke without live dispatch.
- `changed` and `pid` predicate creation and `pending -> firing` evaluation with `--no-dispatch`.
- GitHub Actions CI on the public upstream.

## Known Limits

- `process_done` checks PID liveness only and does not yet guard against PID reuse.
- `file_changed` uses daemon polling of mtime/size rather than inotify.
- CI intentionally does not exercise live tmux paste, Codex hook trust UI, or user systemd service behavior.
