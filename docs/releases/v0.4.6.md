# v0.4.6

Date: 2026-05-20

## Summary

Releases machine-readable doctor diagnostics.

## Included

- Added `codex-wake doctor --json`.
- Factored doctor data collection into one structured summary used by text and JSON output.
- Preserved existing text `doctor` keys for operator compatibility.
- JSON output includes command paths, tmux path, hook config state, hook runtime ack evidence, service state, service paths, repo root, wake root, and trust guidance.
- README now documents `doctor --json` for automation.
- P23 validation evidence for source tests, source CLI smoke, and installed-wheel CLI smoke.

## Verified

- Source tests and compileall.
- Local package build from a temporary build venv.
- Installed-wheel smoke for text `doctor`.
- Installed-wheel smoke for `doctor --json`.
- Installed-wheel `PATH`-first smoke confirming JSON command fields resolve to the isolated install.
- Clean public tag install and doctor JSON smoke.
- GitHub Actions CI on the public upstream.

## Known Limits

- JSON command path fields reflect `PATH` resolution from the calling environment.
- `doctor --json` is an inspection surface only; it does not change service behavior or assert active Codex hook loading without ack evidence.
