# v0.2.0

Date: 2026-05-18

## Summary

Adds operator-managed user service commands to `codex-wake`.

## Included

- `codex-wake service install`
- `codex-wake service status`
- `codex-wake service logs`
- `codex-wake service stop`
- `codex-wake service uninstall`
- Testable user systemd unit rendering in `codex_wake.service`.
- README and service docs updated to prefer the CLI-managed path.

## Verified

- Source tests and compileall.
- Installed CLI help for the service command group.
- User service install, status, logs, stop, and uninstall through `codex-wake service`.

## Known Limits

- Service management targets user systemd only.
- Hook trust remains a Codex `/hooks` operator action.
- The service is still repo-specific; use a distinct service name per repo if needed.
