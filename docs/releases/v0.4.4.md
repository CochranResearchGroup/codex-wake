# v0.4.4

Date: 2026-05-19

## Summary

Releases hook runtime visibility diagnostics.

## Included

- `codex-wake hook check` now reports hook ack evidence from the selected wake root.
- `codex-wake doctor` now reports the same hook ack evidence.
- Added `hook_active_session_loaded=unknown_without_ack|observed_ack`.
- Added latest ack path, submitted timestamp, wake id, and session id fields.
- Documentation now clarifies that no ack means active-session hook state is unknown, not that tmux injection failed.
- P21 validation evidence for source tests, source CLI smoke, and installed-wheel CLI smoke.

## Verified

- Source tests and compileall.
- Local package build from a temporary build venv.
- Installed-wheel smoke for `codex-wake`, `codex-waked`, and `codex-wake-hook`.
- Installed-wheel hook diagnostics smoke covering no-ack and observed-ack states.
- Clean public tag install and hook diagnostics smoke.
- GitHub Actions CI on the public upstream.

## Known Limits

- Ack evidence proves the hook ran only after a wake prompt was submitted.
- No ack does not prove tmux injection failed.
- The diagnostics do not scrape or introspect the active Codex `/hooks` screen.
