# v0.3.0

Date: 2026-05-18

## Summary

Adds hook setup and readiness diagnostics.

## Included

- `codex-wake hook install`
- `codex-wake hook check`
- `codex-wake doctor`
- Hook config helpers for repo-local `.codex/hooks.json`.
- Doctor output for installed commands, tmux, wake root, hook config, service status, unit path, and log path.
- README and hook example updated to use installed `codex-wake-hook`.

## Verified

- Source tests and compileall.
- Installed `hook install`, `hook check`, and `doctor` commands.
- Hook config install/check against a temporary repo.
- Doctor report against this repo.

## Known Limits

- Codex may still require `/hooks` review before a hook can run.
- Doctor reports service status through user systemd only.
- Hook install updates repo-local `.codex/hooks.json`; it does not edit global Codex config.
