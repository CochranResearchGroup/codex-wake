# v0.4.3

Date: 2026-05-19

## Summary

Releases dry-run-first cleanup for archived wake records.

## Included

- Added `codex-wake cleanup`.
- Cleanup is dry-run by default.
- Cleanup deletes only records already under `.codex/wake/archive/`.
- Added `--delete` for explicit deletion.
- Added `--older-than <duration>` with a `30d` default.
- Added `--archive-terminal` to archive terminal records before cleanup evaluation.
- README and runtime-state docs now describe cleanup safety boundaries.
- P20 validation evidence for source tests, source CLI smoke, and installed-wheel CLI smoke.

## Verified

- Source tests and compileall.
- Local package build from a temporary build venv.
- Installed-wheel smoke for `codex-wake`, `codex-waked`, and `codex-wake-hook`.
- Installed-wheel cleanup smoke covering terminal archival, dry-run preview, explicit delete, and archived-list readback.
- Clean public tag install and cleanup smoke.
- GitHub Actions CI on the public upstream.

## Known Limits

- Cleanup does not prune ack files, logs, locks, or event files.
- Cleanup is operator-invoked only; the daemon does not perform automatic retention.
- Archived records without a parseable retention timestamp are skipped rather than deleted.
