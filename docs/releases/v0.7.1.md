# v0.7.1

Fixes the shipped A2A user-service environment: its PATH now includes the stable
user executable directory `~/.local/bin` alongside system executable directories.
This lets the worker locate stock Codex's existing shared daemon without relying
on an interactive shell environment. No daemon bootstrap or restart is added.

The actual v0.7.0 service test admitted a request and reply arm, then exited with
runtime_unavailable before any transport attempt because its manager PATH lacked
the Codex command. Existing request/arm state and the failed test are preserved.
An owned read-only service preflight with the corrected PATH locates the existing
stock daemon successfully. Live installed-service acceptance remains a separate
gate; this patch does not itself prove a delivered round trip or30-minute soak.

Mailbox and wake schemas are unchanged. v0.7.0 remains published; use v0.7.1 for
the corrected service example. The unit retains explicit start, bounded duration
and notification budget, and Restart=no. OpenClaw remains unchanged.
